# MyPhoto 设计文档

> **完整桌面级照片管理软件设计文档**

**目标：** 基于 Tauri 2 + Vue 3 构建桌面级照片管理应用，支持多工作区、网格浏览、选片模式、星级/颜色标签、导出、元数据持久化等核心功能。

---

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端框架 | Vue 3 + TypeScript + Vite | UI 渲染 |
| 桌面容器 | Tauri 2 (Rust) | 原生能力、文件系统 |
| UI 组件库 | Naive UI | 基础组件 |
| 数据库 | SQLite (`rusqlite`) | 元数据持久化 |
| 图片处理 | Rust `image` crate | 格式转换/压缩 |
| 文件监听 | Rust `notify` crate | 实时文件系统变化感知 |
| EXIF 读取 | Rust `kamadak-exif` crate | 读取照片元数据 |
| 状态管理 | Pinia | 前端全局状态 |

## 功能模块详细设计

### 1. 工作区管理

- 顶部 Tab 标签页，每个工作区 = 一个文件夹
- 支持同时打开多个工作区，同一时间只有一个激活
- 每个工作区独立记忆：当前子文件夹、滚动位置、筛选条件、视图模式
- 打开文件夹时：自动扫描照片 + 从 SQLite 加载已有元数据
- `Ctrl+O` 打开新工作区，`Ctrl+W` 关闭当前工作区

### 2. 文件树（左侧栏）

- 显示当前工作区根文件夹的子文件夹树形结构
- 点击文件夹只显示该文件夹中的照片（不递归子文件夹，除非选择"包含子文件夹"）
- 文件夹右键菜单：
  - 在文件管理器中打开
  - 复制路径
  - 重命名
  - 新建文件夹
  - 移入回收站

### 3. 照片网格模式（默认）

#### 网格展示
- **默认：固定方格 fit 模式**——每格固定大小，照片按比例缩放 fit 进方格居中，保留完整画面，多余区域显示灰色背景
- **可切换：等高流式模式**——每行等高，照片按原比例缩放铺满行宽
- 工具栏滑块调整缩略图大小（80px ~ 300px）
- **虚拟滚动**渲染，仅渲染可见区域，支持数万张不卡顿

#### 缩略图标注
- 右下角：星级点（★ 显示评分数量）
- 左上角：颜色标签圆点
- 破图状态：文件丢失时显示🚫图标 + 灰色遮罩

#### 交互
- 单击选中，`Shift+Click` 范围选，`Ctrl+Click` 多选
- **键盘导航**：`←↑↓→` 移动选中，`Enter` 进入大图，`Space` 附加选中
- `Tab` 切换到选片模式

**工作流程**：
1. 进入选片模式，默认显示全部照片在导轨
2. 筛选器缩小范围（如"只看未评分的照片"）
3. `←→` 键或点击导轨切换当前照片
4. 在大图区或导轨缩略图上直接设置星级/颜色标签
5. 完成一轮后调整筛选条件进行下一轮，直到选出满意照片
6. `Tab` 或按钮返回网格模式

### 5. 大图模式

- 双击缩略图进入，全屏黑色背景覆盖层
- `←→` 键或屏幕箭头按钮切换照片
- 鼠标滚轮缩放（最大 10x），拖拽平移
- 底部 HUD 显示：文件名、拍摄时间、相机型号、快门/光圈/ISO/焦距
- 右侧浮动面板：可直接设置星级和颜色标签
- `ESC` 退出

### 6. 元数据面板（右侧栏）

可折叠，显示当前选中照片的：

**基本信息**
- 文件名、文件大小、图片尺寸（宽×高）
- 文件路径

**拍摄参数（EXIF）**
- 相机品牌/型号
- 镜头型号
- 快门速度
- 光圈值（F/N）
- ISO 感光度
- 焦距
- 拍摄时间

**用户标记**
- 星级（可点击修改）
- 颜色标签（可点击修改）
- 备注（可编辑文本框）

### 7. 照片导出

**来源选择**：
- 当前选中的照片
- 按星级筛选（≥N 星）
- 按颜色标签筛选
- 以上条件组合

**设置项**：
- 目标文件夹（系统对话框选择）
- 输出格式：保持原格式 / JPEG / PNG / WebP
- JPEG/WebP 质量：0-100%
- 尺寸限制：原始尺寸 / 按长边限制（输入 px 值）
- 命名规则：原文件名 / 日期+序号 (`YYYY-MM-DD_001`)
- 冲突处理：跳过 / 覆盖 / 重命名

**导出进度**：后台 Rust 处理，弹窗显示进度条，完成后可在文件管理器中打开目标文件夹。

### 8. 文件同步（外部修改感知）

**检测机制**：
- 打开工作区时：全量扫描，对比 `file_modified_at` 和 `is_missing`
- 运行期间：使用 `notify` crate 监听文件夹变化（实时）

**处理逻辑**：

| 情况 | 行为 |
|------|------|
| 文件被删除 | 缩略图显示🚫，状态栏警告"X 张照片文件已丢失"；右键菜单增加"从库中移除"和"重新定位..." |
| 文件被修改 | 自动重新读取 EXIF 更新数据库；用户的星级/颜色标签保留 |
| 新文件被加入 | 通知栏提示"发现 N 张新照片"，提供[立即添加][忽略]按钮 |

### 9. 快捷键系统

**帮助面板**：`?` 键或菜单 `帮助 → 快捷键` 打开，分组展示，支持搜索

**可在设置页面**：重新绑定任意快捷键，或禁用某个快捷键，配置持久化到 SQLite

## 数据库模型（SQLite）

```sql
-- 工作区
CREATE TABLE workspaces (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  path TEXT NOT NULL UNIQUE,
  name TEXT NOT NULL,
  last_opened_at TEXT,
  settings_json TEXT DEFAULT '{}'
);

-- 照片索引
CREATE TABLE photos (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  workspace_id INTEGER NOT NULL,
  relative_path TEXT NOT NULL,
  filename TEXT NOT NULL,
  file_size INTEGER,
  width INTEGER,
  height INTEGER,
  taken_at TEXT,
  camera_make TEXT,
  camera_model TEXT,
  lens_model TEXT,
  shutter_speed TEXT,
  aperture REAL,
  iso INTEGER,
  focal_length REAL,
  file_modified_at TEXT,
  is_missing INTEGER DEFAULT 0,
  UNIQUE(workspace_id, relative_path)
);

-- 用户元数据
CREATE TABLE photo_meta (
  photo_id INTEGER PRIMARY KEY,
  star_rating INTEGER DEFAULT 0,
  color_label TEXT DEFAULT '',
  notes TEXT DEFAULT '',
  created_at TEXT,
  updated_at TEXT,
  FOREIGN KEY(photo_id) REFERENCES photos(id) ON DELETE CASCADE
);

-- 快捷键配置
CREATE TABLE keybindings (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  action_id TEXT NOT NULL UNIQUE,
  key_combo TEXT NOT NULL,
  enabled INTEGER DEFAULT 1
);
```
