# MyPhoto

> 📖 [English version → README_EN.md](README_EN.md)

MyPhoto 是一款本地桌面照片管理工具，专注于摄影工作中的四件事：**浏览、筛选、选片、导出**。

## 这款软件解决什么问题

拍完一组照片后，常见痛点是：

- 文件很多，翻起来慢
- 选片标准不统一，回看困难
- 导出规则重复设置，容易出错
- 文件名混乱，后续管理麻烦

MyPhoto 的目标是把这些流程变成一套顺手、稳定、可重复的工作方式。

## 核心体验

### 1) 快速浏览

- 支持多工作区（标签页）切换
- 网格模式下可快速滚动浏览大量照片
- 可调缩略图大小，方便在“看全局”和“看细节”之间切换

### 2) 直接筛选

- 在网格顶部直接做排序、全选/取消全选
- 支持星级筛选和颜色筛选
- 即使筛选结果为空，也能继续调整筛选条件

### 3) 高效选片

- 选片模式提供大图 + 胶片轨
- 左右切片流畅，支持重新从第一张开始
- 可在选片过程中直接打星、上色、标记

### 4) 文件整理

- 文件树支持右键操作：重命名、新建、删除、刷新、重扫
- 支持“批量重命名全部图片”，适合处理下载后乱码文件名

### 5) 可控导出

- 导出范围：已选 / 全部 / 仅有星级
- 输出格式：原格式 / JPEG / PNG / WebP
- 支持质量与尺寸限制
- 同名冲突可选：跳过 / 覆盖 / 自动重命名
- 自动重命名支持：自定义前缀 + 序号/日期/时间戳后缀
- 导出过程有独立进度弹窗和结果统计

### 6) 更少等待

- 应用会自动准备常用缩略图，减少首次打开卡顿
- 右下角有统一进度卡片，可最小化/展开
- 缓存可在设置里查看和重建

## 主要功能清单

- 网格模式、选片模式、大图查看
- 星级、颜色标签、备注
- EXIF 信息查看
- 文件树右键管理
- 网格右键：打开、定位、复制路径、导出、复制/移动、删除
- 快捷键帮助面板与快捷键自定义
- 最近打开工作区

## 快速开始（使用者）

1. 打开软件
2. `Ctrl+O` 选择照片文件夹
3. 在网格中初筛并打标
4. 切到选片模式做精筛
5. 右键导出选中照片

| 操作 | 快捷键 |

| 打开工作区 | `Ctrl+O` |
| 关闭工作区 | `Ctrl+W` |
| 打开设置 | `Ctrl+,` |

## 常见问题

### 为什么重启后有时会看到“同步文件索引”？

这是正常行为。软件会确认你的文件夹有没有变化（如新增、删除、改名）。  
如果没有变化，会很快结束；如果有变化，会自动更新索引。

### 重建缓存会不会和当前任务冲突？

不会。重建前会先停掉当前相关任务，再开始重建。
